# פנקס הפוקר — Wooly Bluff Poker Club

טבלת הניצחונות של ערב הפוקר השבועי. עמוד סטטי, מתארח ב‑GitHub Pages.

**האתר:** https://zivmiz.github.io/poker-ledger/

## איך מעדכנים ערב חדש

1. נכנסים לאתר ולוחצים **כניסת מנהל** (בתחתית העמוד).
2. מוסיפים או עורכים ערבים דרך הממשק — השינויים נשמרים בדפדפן בלבד.
3. מופיעה שורה כתומה למעלה: **העתק JSON** ← **פתח את data.json** ← מדביקים במקום כל התוכן ולוחצים *Commit changes*.

תוך כדקה GitHub Pages מפרסם מחדש וכולם רואים את הטבלה המעודכנת.

אפשר כמובן גם לערוך את `data.json` ידנית.

## מבנה `data.json`

```jsonc
{
  "v": 1,
  "sample": true,          // true = נתוני דוגמה; יורד לבד אחרי העריכה הראשונה
  "nights": [
    {
      "id": "seed-0",
      "date": "2026-09-17",
      "results": {
        "זיו": 4,          // מספר הניצחונות באותו ערב
        "פלח": null        // null = לא שיחק (מסומן באדום בטבלה)
      }
    }
  ]
}
```
